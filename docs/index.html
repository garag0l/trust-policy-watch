What the policy says
Logic ported from trust-policy-watch, an open-source IAM trust-policy drift detector by Murat Bekgi (MIT). This page is a read-only single-policy inspector; the full tool snapshots roles across an account and alerts on drift (TPW-001…006) in CI.
Severity here is static guidance on one policy, not an account-wide audit. A cross-account trust may be entirely intended — the point is to make it visible.
